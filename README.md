# Trivia-Guri
Un juego tipo Trivia o Quiz con un fin educativo y pedagógico  para que los niños  de primaria aprendan  de forma didáctica y recreativa, trabajamos con  el grado  que cursan (1ro a 6to de primaria)  la asignatura elegida , y por cada asignatura tenemos preguntas múltiples con respuestas con el objetivo de enseñar.
